# ADR 0006 — Grenze des Referenzartefakts

- **Status:** Superseded by `ADR 0008-Reference`
- **Datum:** 2026-07-23

## Entscheidung

SecAware.NRW wird unverändert in einem separaten Tab geöffnet. Kein Iframe, kein Kopieren oder
Redesign des Inhalts. Zugriffspfad, Datum, sichtbare Version, Checks und Completion-Pfad werden
vor der Hauptstudie eingefroren.

## Konsequenzen

- Die Studie misst die Gesamtartefaktzeit, nicht interne SecAware-Segmente.
- Nichterreichbarkeit ist ein technischer Abbruch.
- Beide Bedingungen erhalten dieselben neutralen Vor- und Nachschritte.
