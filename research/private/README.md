# Private research sources

This directory is intentionally excluded from Git. It contains the thesis source material used
for local authoring and precise Codex tasks:

- `training-script.pdf` — current training script and segment source;
- `expose.pdf` — bachelor-thesis exposé;
- `translation-foci.tex` — artifact-scope translation and TF1–TF6 source text;
- `design/passwo-character-system.png` — PassWo character/design reference;
- `design/passwo-browser-flight-concept.png` — browser-flight composition reference.

Do not push these files to a public repository. Agent tasks should normally use the concise
material under `research/derived/` and open a private source only when a prompt explicitly names
it and limits the relevant page or section.
